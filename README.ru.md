# Wawity VPN | wawity.lol

**Wawity** — VPN-клиент для Windows на базе [sing-box](https://github.com/SagerNet/sing-box). Поставляется как настольное GUI-приложение (Tauri + Vue 3) и как консольный клиент, оба варианта работают на общем Rust-движке, который отвечает за разбор протоколов, управление процессом sing-box и блокировку трафика через Windows Firewall.

🇬🇧 English version: [README.md](./README.md)

> Отдельный мобильный порт находится в соседнем проекте `wawity-android` (Tauri 2 + Kotlin) и не входит в этот репозиторий.

## Обзор

Wawity подключается к серверам-прокси по стандартным ссылкам-подпискам (VLESS, VMess, Trojan, Shadowsocks, Hysteria2) и пропускает трафик через [sing-box](https://github.com/SagerNet/sing-box) через TUN-интерфейс (`wintun.dll`). Поверх этого добавлен полноценный десктопный опыт: kill switch, режим постоянной блокировки (always-on), мульти-хоп маршрутизация, раздельное туннелирование, блокировка рекламы и трекеров, управление из трея, горячие клавиши, интеграция с Discord Rich Presence и двуязычный (EN/RU) интерфейс с анимированным космическим фоном.

Продукт собирается в двух вариантах из одной кодовой базы:

- **Wawity Desktop** — полноценное GUI-приложение (`wawity-app.exe`) на Tauri.
- **Wawity CLI** — лёгкий консольный/TUI-клиент (`wawity.exe`) для безголового использования или на сервере, собран на `ratatui`.

## Возможности

**Ядро VPN**
- Поддержка протоколов: VLESS, VMess, Trojan, Shadowsocks, Hysteria2 (тип подписки определяется автоматически).
- Импорт подписки по вставленной ссылке; автоматический перебор User-Agent'ов и типов содержимого при загрузке.
- Замер пинга/задержки серверов и геолокация для списка серверов.
- Постквантовое шифрование: гибридный обмен ключами **X25519 + ML-KEM768**.

**Защита сети**
- **Kill Switch** — блокирует весь трафик, если туннель обрывается.
- **Always-On (постоянная блокировка)** — блокирует доступ в интернет до подключения к серверу, реализовано через Windows Firewall (COM API `INetFwPolicy2`) с фоновым watchdog, который обнаруживает и восстанавливает "уплывшие" правила файрвола.
- **Защита от DNS-утечек** — блокирует локальный DNS, LLMNR, mDNS и NBNS, которые могли бы обойти туннель.
- **Мульти-хоп маршрутизация** — трафик идёт через входной и выходной сервер (`вход → выход → назначение`).
- **Раздельное туннелирование (split tunneling)** — включение/исключение конкретных приложений, доменов или диапазонов IP из туннеля; приложение сканирует установленные игры и программы, чтобы их было проще выбрать.
- **Блокировка рекламы и трекеров** — используются geosite-списки `sing-box` (`geosite-category-ads-all`, `geosite-private`).

**Десктопный опыт**
- Значок в трее с быстрым подключением/отключением, переподключением и восстановлением сети, а также мини-интерфейс во всплывающем окне трея.
- Настраиваемые глобальные горячие клавиши (работают даже когда окно скрыто).
- Нативные уведомления.
- Интеграция с Discord Rich Presence (опционально показывает подключённый сервер/подписку).
- Автозапуск при старте системы с возможностью запуска свёрнутым в трей.
- Анимированный космический фон (чёрная дыра / пульсар / нейтронная звезда / туманность) с переключаемым уровнем детализации (простой/кинематографичный) для слабых видеокарт.
- Двуязычный интерфейс: английский и русский, переключаются на ходу.

**CLI-клиент**
- Интерактивный терминальный интерфейс (`ratatui` + `crossterm`) на том же движке, что и десктоп-приложение, плюс скриптуемый набор команд на `clap`.

## Архитектура

Репозиторий — это Cargo workspace из трёх участников, плюс фронтенд на Vue и отдельный проект установщика:

```
Cargo.toml                 # корень workspace (resolver = "2")
crates/
├── wawity-core/           # общий движок: разбор/генерация конфигов,
│                          # управление процессом sing-box, блокировка
│                          # через Windows Firewall, роутинг/TUN/QoS
└── wawity-cli/            # консольный бинарник "wawity": clap CLI + ratatui TUI
src-tauri/                 # десктоп-приложение на Tauri 1.8 (бинарник "wawity-app")
│                          # интеграция с Win32: COM API файрвола, глобальные
│                          # горячие клавиши, эффекты окон DWM, трей,
│                          # Discord Rich Presence, сканирование игр/программ
src/                       # фронтенд на Vue 3 + Pinia + Vue Router + TypeScript
installer/                 # отдельный Rust-проект, который собирает
                            # Windows-установщик (WawitySetup-*.exe)
telemetry-relay/           # опциональный Node.js-релей для телеметрии (opt-in)
```

- **`wawity-core`** максимально независим от протокола и платформы: содержит разбор подписок (`config::parser`), генерацию конфига sing-box (`config::generator`), супервизор процесса и управление сетью/файрволом Windows.
- **`src-tauri`** подключает движок к нативному окну: регистрирует все Tauri-команды, которые использует фронтенд, управляет окнами сплэша/главного окна/трея/уведомлений и владеет специфичными для Win32 частями (правила файрвола, горячие клавиши, оформление окна).
- **`src`** — обычное SPA на Vite + Vue 3. Состояние хранится в одном Pinia-хранилище (`stores/vpn.ts`), которое общается с бэкендом исключительно через `invoke`/`listen` из `@tauri-apps/api`.
- **`installer/`** — отдельный Cargo-проект (исключён из основного workspace), который упаковывает загрузчик WebView2, собранный бинарник, `sing-box`, `wintun.dll` и geosite-правила в один установщик в стиле NSIS.
- **`telemetry-relay/`** — небольшой независимый Node.js HTTP-сервис; десктоп-приложение обращается к нему только если телеметрия включена в настройках.

## Требования

- Windows 10/11, x64.
- Приложение запрашивает права администратора при запуске (самоповышает через UAC), так как напрямую управляет Windows Firewall и сетевым стеком.
- Для сборки из исходников: Node.js (npm), набор инструментов Rust (`cargo`) и, на Windows, MSVC Build Tools для линковки.

## Быстрый старт

### Фронтенд / десктоп-приложение (dev-режим)

```bash
npm install
npm run dev          # dev-сервер Vite
# во втором терминале
cargo build -p wawity          # debug-сборка Tauri-приложения
```

### CLI-клиент

```bash
cargo build -p wawity-cli --release
target/release/wawity.exe
```

### Сборка через build.bat

`build.bat` — это интерактивное меню для сборки установщиков:

```
[1] DESKTOP   — фронт + Rust + установщик   → dist-build\WawitySetup-Desktop.exe
[2] CLI       — бинарник + установщик        → dist-build\WawitySetup-CLI.exe
[3] Оба продукта подряд
[4] Очистка сборки
[5] Диагностика cargo: реестр и сеть
```

Скрипт автоматически определяет глобальное зеркало реестра cargo (`replace-with`) и, если находит, перенаправляет сборку в изолированный `CARGO_HOME` (`.cargo-home/`), чтобы зеркало не мешало. Если хотите отключить зеркало в глобальном `~/.cargo/config.toml` совсем — используйте `fix-cargo-mirror.bat`.

### Ручная сборка установщика

Перед запуском упаковки установщика (`installer\`) должны существовать следующие файлы:

- `installer/payload/MicrosoftEdgeWebView2Setup.exe` — загрузчик WebView2 Evergreen Bootstrapper (скачивается отдельно).
- `src-tauri/binaries/sing-box-x86_64.exe` и `src-tauri/binaries/wintun.dll` — уже включены в репозиторий.
- `src-tauri/rulesets/*.srs` — geosite-правила для блокировки рекламы/трекеров, уже включены.

`build.bat` упаковывает всё это в `installer/payload/app.zip`, а затем собирает Cargo-проект `installer`, который создаёт `WawitySetup-Desktop.exe` / `WawitySetup-CLI.exe` в папке `dist-build\`.

## Телеметрия

Wawity может опционально отправлять анонимные события использования (подключение/отключение, ошибки), чтобы помогать в диагностике проблем. Это переключатель в настройках — включён он или выключен по умолчанию, зависит от вашей сборки; актуальное состояние смотрите на странице **Настройки** в приложении. При включении события отправляются на самостоятельно развёрнутый релей (`telemetry-relay/server.mjs`), который проверяет запросы по ключу доступа, ограничивает частоту запросов по IP и периодически отправляет сводку в Telegram-чат через бота. Ни один код телеметрии не выполняется, если релей не развёрнут и не настроен тем, кто собирает/эксплуатирует этот конкретный экземпляр.

Переменные окружения релея:

| Переменная | Назначение |
|---|---|
| `TG_BOT_TOKEN` | токен Telegram-бота для отправки сводок |
| `TG_CHAT_ID` | чат, куда отправляются сводки |
| `INGEST_KEY` | общий секрет, который должно предъявлять приложение |
| `PORT` | HTTP-порт (по умолчанию `8787`) |
| `DIGEST_MINUTES` | интервал сводки, минимум 5 минут |

## Локализация

Интерфейс поставляется с английским (`src/i18n/en.ts`) и русским (`src/i18n/ru.ts`) переводами, переключаемыми на ходу из настроек. Чтобы добавить новый язык, нужно создать новый файл локали с той же структурой ключей и зарегистрировать его в `src/i18n/index.ts`.
