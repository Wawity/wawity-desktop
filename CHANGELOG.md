# Changelog

Все заметные изменения проекта Wawity документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.2.0] — 2026-08-28

Крупный релиз: более 260 изменённых файлов, ~18 400 добавленных строк.
Основные усилия — профили трафика (роли), умный выбор сервера, учёт трафика
и набор сетевых утилит внутри приложения.

### Добавлено

**Роли — профили раздельного туннелирования**
- Пять встроенных профилей: Standard, Work, Gaming, Streaming, Privacy —
  каждый со своими настройками DPI, DNS и правилами маршрутизации.
- Создание, переименование и удаление собственных ролей.
- Правила маршрутизации по доменам, IP и портам для каждой роли.
- Провайдеры правил (rule providers): подключение внешних списков доменов,
  обновление и включение/отключение для конкретной роли.
- Переключение активной роли в один клик.

**Умный выбор сервера**
- Модуль `smartpick` (Rust): параллельное глубокое пробингование серверов
  (12 одновременных соединений, 4 раунда, замер TCP/TLS-рукопожатий).
- Скоринг серверов на основе истории задержек, неудачных попыток и обрывов.
- Автоматический выбор лучшего сервера (умный или быстрый режим).
- Калибровка отказоустойчивости и настраиваемый список failover-серверов.

**Учёт трафика**
- Локальная история трафика по подпискам (дни, rx/tx), сохраняется между запусками.
- Сводка за сегодня и за неделю на панели анализа.
- Квоты подписки: отслеживание остатка и уведомления при 20% / 5% / 0%.

**Автоотключение (Auto-Off)**
- Отключение VPN по таймеру (часы:минуты в интерфейсе).
- Отключение при закрытии выбранного процесса (например, игры) —
  фоновый наблюдатель `appwatch`.

**Сетевые утилиты (новый раздел Extra)**
- **Reachability** — проверка доступности серверов.
- **Speed Test** — замер скорости загрузки/отдачи через Cloudflare
  (модуль `netprobe`).
- **Leaks** — диагностика утечек DNS/IP.
- Каждая утилита — отдельная страница с общим каркасом `ExtraPage`.

**Прочее в интерфейсе**
- Избранное: отмечайте серверы звёздочкой и подключайтесь к ним быстро.
- Группы серверов: свои категории с целевым сервером для группы.
- Бейджи подписок (цветные метки) и иконки подписок.
- HWID: просмотр, включение/выключение и сброс идентификатора устройства.
- Мульти-хоп подключение цепочкой (connect with chain).
- Авто-переподключение после сна системы и обрывов сети
  с уважением к ручному отключению.
- Новые визуальные компоненты: ThinkingOrb, CopyHint, ServiceMark;
  material.css; хелперы motion/useTilt/reactMount.
- Локализация EN/RU выросла примерно вдвое (414 → 838 строк на язык).

**Сайт и документация**
- Лендинг в `public/`: главная, документация, контакты, политика
  конфиденциальности, условия использования, скриншоты.

**Инфраструктура**
- CI: GitHub Actions workflow для сборки и публикации установщиков.
- Репозиторий приведён к воспроизводимой сборке: `.gitignore`
  (исключены `target/`, `node_modules/`, кеш, артефакты), бинарник
  `sing-box` и payload установщика добавлены в репозиторий.
- Лицензия MIT (`LICENSE`).

### Изменено
- Хранилище состояния фронтенда (`stores/vpn.ts`) выросло с 1 276 до 2 865 строк.
- README (EN/RU) переписан под новую структуру и возможности.
- Версии в `Cargo.toml`, `tauri.conf.json`, `package.json` подняты до 0.2.0.

### Исправлено
- Самопроизвольное переподключение после ручного отключения при включённом
  auto-connect: теперь намерение пользователя (disconnect intent) учитывается
  при отключении из окна, из трея и глобальной горячей клавишей; авто-реконнект
  работает только в главном окне и только после обрыва связи.

### Удалено
- Служебные PowerShell-скрипты (`init.ps1`, `sign.ps1`, `make_payload.ps1`)
  исключены из репозитория и добавлены в `.gitignore`.

## [0.1.0] — первый публичный снапшот

- Десктоп-клиент (Tauri 1.8 + Vue 3): подключение по подпискам VLESS/VMess/
  Trojan/Shadowsocks/Hysteria2, kill switch, always-on блокировка, мульти-хоп,
  раздельное туннелирование, блокировка рекламы/трекеров.
- Системный трей с мини-UI и горячие клавиши.
- Discord Rich Presence, автозапуск с окном в трее, уведомления.
- CLI/TUI-клиент `wawity` на том же движке.
- Установщик (отдельный Cargo-проект) и релей телеметрии.
